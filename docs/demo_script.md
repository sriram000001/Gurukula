# Demo Script

1. Open the app — take the 2-question diagnostic, deliberately get the linear-equations
   question wrong.
2. Path generates: shows the target chapter with a "current" node.
3. Click **Simulate: Fail** on the current node → path re-sequences live, inserting a
   remediation node ("Quick review: solving equations with variables on both sides")
   with a rationale explaining why.
4. Click **Simulate: Pass** on the remediation node → it marks complete, unlocks the
   next real node, and shows the encouragement message.
5. Say out loud: "This isn't a static syllabus — it reacted to the exact gap the
   student showed, in real time."
